## 📌 Descrição

Sistema desenvolvido em Python para leitura, auditoria e criptografia de arquivos confidenciais.

O projeto permite:

- Ler arquivos XML, CSV e JSON
- Exibir dados em tabela dinâmica (Treeview)
- Registrar auditoria em tempo real
- Criptografar arquivos utilizando AES/Fernet
- Gerar Hash SHA-256 para integridade dos dados
